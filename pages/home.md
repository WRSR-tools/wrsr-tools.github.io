# `wrsrcli` - an asset manager for Workers and Resources

`wrsrcli` is an asset manager under development for Workers and Resources: Soviet Republic. 

Current features include:

- Scan and create a manifest file of all workshop download
- Create an HTML table listing basic information about your assets
- Import assets lists
  + Fetch missing downloads automatically
  + Automated moving and backup procedure for manual install assets
