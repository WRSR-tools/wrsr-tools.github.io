# WMLS - WRSRCLI Markup Language Standard

The WMLS is the standard format accepted by `wrsrcli` when parsing imports. If you would like to create your own lists, please familiarise yourself with the current standard to make sure that your files are accepted by the tool.

The standard is based on YAML. It is a relatively simple language where indentation (two empty spaces, `  `) and dashes (`-`) define the various actions that each item can take.
